IMPORTANT - READ BEFORE OPENING IN ANDROID STUDIO
==================================================

1. Copy YOUR original gradlew and gradlew.bat files into the root of this folder.
   (These are the executable Gradle wrapper scripts from your original project)
   
2. Copy the gradle/wrapper/gradle-wrapper.jar file from your original project into:
   gradle/wrapper/gradle-wrapper.jar
   
3. Copy your original drawable resources (auto.png/xml and userlogo.png/xml) into:
   app/src/main/res/drawable/
   (These image assets cannot be regenerated)

4. Open the AutoTrader folder in Android Studio using:
   File > Open > select the AutoTrader folder

5. Default login credentials:  admin / admin123

That's it - the project should sync and build.
